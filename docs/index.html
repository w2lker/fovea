Sharp focus on what matters in your agent’s tool output.

The rest stays in the periphery: collapsed into outline lines the agent can see, and read in full whenever it needs to. Fovea selects. It never paraphrases, and it never deletes.

Get started See how we measured it

The fovea is the small central pit of the retina, about 2° of the visual field. Only there does the eye see sharply. The periphery is blurry, but you know it is there, and you can look at it.

System 1, System 2. Daniel Kahneman’s fast, intuitive judgement in front of slow, expensive reasoning. Fovea puts a fast relevance judge in front of the coding agent.

WYSIATI. “What you see is all there is”: a mind reasons confidently from whatever it was shown. A filter that silently drops text makes an agent confidently wrong.

How it works

A fast judge in front of a slow reasoner.

Fovea sits between Claude Code’s Bash tool and the model. Small outputs pass untouched. Large ones go through three steps.

  1. inputTool output
    git log, grep, a long listing, a JSON dump
  3. 1 · splitNatural blocks
    One commit, one file’s matches, one section, one diff hunk.
  5. 2 · judgeSystem 1 relevance score
    block 1p = 0.03
    block 2p = 0.91
    block 3p = 0.07
    block 4p = 0.12
    A decision model returns a probability, not text. One request per output, about 0.45 s.
  7. 3 · p ≥ thresholdVerbatim blockOriginal text, original line numbers.
    3 · p < thresholdOutline lineA range and a short label. Full text one command away.

Verbatim

Fovea never summarises or rewrites. What reaches the model is either the original text or a clearly marked omission.

Visible

Every skipped range leaves an outline line. The agent always knows the shape of what it is not seeing.

Reversible

The full output is saved to disk, for 30 days by default. When filtering goes wrong, the agent reports it with fovea note.

When Fovea stays out of the way

Outputs under about 1,000 tokens, errors and stack traces, output the agent already trimmed with sed -n, head or tail, outputs that look like they contain secrets, and any command it is told to bypass all pass through unchanged. So does everything when no judge key is set, or when the judge is slow or unavailable.

How the test set was built

Inputs. 30 tool outputs in six formats (JSON, git log, markdown, grep, code and more), 1,140 blocks in total. For publication the set will be rebuilt on a different codebase.

Tasks. 90 agent tasks in three phrasings: with exact identifiers, paraphrased, and in casual Russian.

Labels. Three independent labeler models (Sonnet, Opus, Minimax), agreement 97.8–99.3%, Cohen’s κ 0.81–0.93. Results use the majority vote.

Limitations

What it does not do yet.

Bash outputs only

v1 filters shell commands. File reads through the editor tool and MCP tool outputs are not covered yet.

Outputs at Claude Code’s limit

Claude Code cuts a Bash output at its limit (30,000 bytes by default) before any hook sees it. Those outputs pass through as they are.

Little saving on code

Source files keep about 65% of their text. Fovea is safe there, but it is not where it pays off.

One calibrated judge

The defaults were calibrated on TypeSafe Jev only. Another endpoint or model is your choice and responsibility, threshold included.

A modest test set

30 outputs and 90 tasks. Recall 1.00 on this set is not a guarantee on yours; fovea report shows your measured losses. Live sessions are still to be validated.

A network call per large output

About 0.45 s and $0.0006 each. Small outputs skip the judge entirely.

Pre-release

Interfaces and defaults may change before the first tagged version.

Quick start

Install, then forget it is there.

# 1. Get the code (Python 3.9+, standard library only)
git clone https://github.com/w2lker/fovea
ln -s "$PWD/fovea/bin/fovea" ~/.local/bin/fovea

# 2. Give the judge an API key (OpenRouter by default)
export OPENROUTER_API_KEY=…

# 3. Register the hook in Claude Code, then watch it first
export FOVEA_MODE=shadow

# 4. After a session: savings and measured losses
fovea report

Register fovea/hook.py as a PostToolUse hook with matcher Bash and a 10 second timeout, and fovea/session_start.py as a SessionStart hook. There is no packaged installer yet.

In shadow mode Fovea decides and logs but leaves every output unchanged, so you can see what it would have saved and lost on your own sessions. When the agent notices a filter went wrong, it calls fovea note. Those notes show up in fovea report next to the savings.
